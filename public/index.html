共 通 環 境 変 数

  • DATABASE_URL ― Neon PostgreSQL 接続
  • ACCESS_PIN ― 一般アクセス用 PIN
  • ADMIN_PIN ― 管理者用 PIN
  • ANTHROPIC_API_KEY ― Claude API キー（AI 系のみ）

御 約 束 事

  • main 直接コミット・Vercel 自動デプロイ

  • 利用者の個人情報はログに出力せず
  • API 応答に role（権限）を必ず含む
